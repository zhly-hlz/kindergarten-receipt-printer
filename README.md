# 幼儿园收据打印工具（离线单文件）

一个纯前端、单 HTML 文件的幼儿园收据打印工具：**不用安装、不用联网、不传数据到服务器**。双击网页文件即可使用，A4 竖纸一页打印 3 张收据（175 × 94 mm）。

> 🔒 **隐私说明**：本仓库发布的代码已移除所有真实学生名单。工具运行时数据只保存在你本机浏览器（localStorage），不会上传到任何地方。导出的备份 JSON 含学生信息，请自行妥善保管。

## ✨ 功能

- 勾选学生批量生成收据，编号自动递增、支持补打（不占新编号）
- 日期独立一行、金额大小写自动转换（含「叁万零伍拾陆」等易错金额）
- 收费项目可增删改、逐个学生可单独调整金额与勾选项目
- 会计 / 出纳 / 经手人签名栏，打印记录自动存档
- 支持从 Excel / CSV 导入名单、导出与恢复 JSON 备份
- 设置弹窗可直接修改起始收据编号

## 🚀 快速开始

1. 下载 `收据打印工具.html` 到电脑任意文件夹（建议桌面）。
2. **双击**用 Edge / Chrome 打开（不要在聊天软件的预览窗口里长期使用，预览窗口不保存数据）。
3. 点「📥 导入名单」，选择按模板填写的 Excel / CSV。最低要求：有一列名为「学生姓名」的表头。
4. 勾选学生、核对金额、填写签名，点「🖨️ 打印收据」。
5. 打印设置：A4、纵向、缩放 100%（页边被裁可试 90%~95%）、边距默认。

## 🏫 换成自己的园所名称

在 HTML 中搜索 `const ORG`，把引号里的园所名改成自己的即可：

```js
const ORG = 'XX幼儿园';   // 园所名称写死
```

收费项目名称和标准金额在页面「⚙️ 设置」里改，改完点「保存设置」。

## 📋 导入名单格式

| 学生姓名 | 学生学号 | 性别 | 出生日期 | 年级 | 班级 |
| --- | --- | --- | --- | --- | --- |
| 张三 | 001 | 男 | 2020-09-01 | 大班 | 大A班 |

只有「学生姓名」列必填；建议保留「班级」列以便筛选。表头下隔两行写收费项目和金额时，导入后会自动更新收费设置。

## 💾 数据与安全

- 数据存在**当前电脑的浏览器**里，不同电脑之间不自动同步。
- 清理浏览器缓存 / 重装系统前，先「💾 导出备份」；换电脑后「📂 从备份恢复」。
- 备份 JSON 包含学生姓名、班级、打印记录，含敏感信息，请勿随意公开发布。
